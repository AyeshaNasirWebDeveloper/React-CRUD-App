# Firebase Product Management App

This is a **Firebase-based Product Management App** built with React, Vite, and Tailwind CSS. It allows users to add, edit, delete, and view product details. The app uses Firebase Firestore for real-time data storage and retrieval.

## Features

- **Add Products**: Add new products with details like title, price, image URL, and category.
- **Edit Products**: Update existing product details.
- **Delete Products**: Remove products from the list.
- **View Products**: Display a list of products in a table format.
- **Search Functionality**: Search for products by name.
- **Responsive Design**: The app is fully responsive and works on mobile, tablet, and desktop devices.
- **SweetAlert Notifications**: Display success and error notifications using SweetAlert2.

## Technologies Used

- **Frontend**:
  - React
  - Vite (for fast development and build)
  - Tailwind CSS (for styling)
  - SweetAlert2 (for notifications)
- **Backend**:
  - Firebase Firestore (for real-time database)
  - Firebase Authentication (optional, if implemented)

## Getting Started

Follow these steps to set up the project locally on your machine.

### Prerequisites

- Node.js (v16 or higher)
- npm (v8 or higher)
- Firebase account (for Firestore setup)
